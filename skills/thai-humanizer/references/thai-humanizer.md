# ร่องรอยภาษา AI ในงานเขียนวิชาการภาษาไทย

ใช้คู่กับสกิล `humanizer` (ซึ่งเขียนสำหรับภาษาอังกฤษ) เป้าหมายคือให้อ่านเหมือนนักวิชาการไทยเขียนเอง โดย **ไม่เปลี่ยนข้อเท็จจริง ตัวเลข การอ้างอิง หรือข้อเสนอ**

ไฟล์นี้ใช้ *หลัง* ร่างเพื่อเก็บตก ส่วนแม่แบบย่อหน้า คลังคำเชื่อม และตารางสำนวนแปลชุดใหญ่ที่ใช้ *ขณะ* ร่าง อยู่ใน `thai-prose-patterns.md` ตัวเลขความถี่ของร่องรอยให้ดูจาก `scripts/thai_style_check.py` ข้อความใน `[ตัวบท]...[/ตัวบท]` และข้อความยกตรงในเครื่องหมายคำพูด ห้ามแก้

## รูปแบบที่ต้องหาและแก้

| ร่องรอย | ตัวอย่าง | แก้เป็น |
|---|---|---|
| เปิดเรื่องแบบสำเร็จรูป | "ในยุคปัจจุบันที่โลกเปลี่ยนแปลงอย่างรวดเร็ว..." "ในโลกยุคดิจิทัล..." | เปิดด้วยข้อเท็จจริงเจาะจง เหตุการณ์ สถิติ หรือปัญหาในพื้นที่ (ดูแบบแผนบทนำใน mcu-journals.md) |
| ไม่เพียงแต่...แต่ยัง... / มิใช่...หากแต่... ใช้ถี่ | ทุก 2-3 ย่อหน้า | ใช้ได้ไม่เกิน 1-2 ครั้งทั้งบทความ ที่เหลือเขียนตรง ๆ |
| ไตรภาคบังคับ | "ทั้งด้านเศรษฐกิจ สังคม และสิ่งแวดล้อม" ทุกที่ | แจกแจงตามจำนวนจริง 2 หรือ 4 ก็ได้ |
| คำขยายเกินจริง | อย่างยิ่ง, อย่างมีนัยสำคัญ (ที่ไม่ใช่สถิติ), อย่างลึกซึ้ง, อย่างก้าวกระโดด, ปฏิวัติวงการ, กุญแจสำคัญ, หัวใจสำคัญ, ขับเคลื่อน (ซ้ำ ๆ) | ตัดทิ้ง หรือใส่ตัวเลข/หลักฐานแทน; "มีนัยสำคัญ" สงวนไว้สำหรับผลสถิติ |
| คำเชื่อมซ้ำต้นย่อหน้า | "นอกจากนี้", "อย่างไรก็ตาม", "ดังนั้น", "ทั้งนี้" ขึ้นต้นหลายย่อหน้าติดกัน | สลับ หรือตัด ให้ประโยคหลักนำย่อหน้าเอง |
| ประโยคปิดสรุปทุกย่อหน้า | "...ซึ่งสะท้อนให้เห็นถึงความสำคัญของ..." "...จึงเป็นสิ่งที่ไม่อาจมองข้ามได้" | ปิดย่อหน้าด้วยข้อสรุปเฉพาะของย่อหน้านั้น หรือไม่ต้องปิด |
| คำสรุปลอย ๆ | "กล่าวโดยสรุป", "โดยสรุปแล้ว" กลางบทความ | ใช้เฉพาะในส่วนสรุป |
| คำนามนามธรรมซ้อน | "การดำเนินการในการพัฒนาการบริหารจัดการ" | ใช้กริยา: "พัฒนาการบริหาร" |
| ขีด em-dash / เครื่องหมาย — | ภาษาไทยวิชาการไม่ใช้ | เปลี่ยนเป็นจุลภาค วงเล็บ หรือแยกประโยค |
| ตัวหนา/บูลเล็ตในร้อยแก้ว | ย่อหน้าเนื้อหาเป็นข้อ ๆ มีหัวข้อตัวหนา | เขียนเป็นร้อยแก้ว ใช้ "ประการแรก... ประการที่สอง..." หรือ 1) 2) 3) ในบรรทัดเดียวกัน |
| ภาษาขายของ/ปลุกใจ | "ก้าวสู่อนาคตที่ยั่งยืน", "ปลดล็อกศักยภาพ", "เปิดประตูสู่" | ภาษาเป็นกลาง เชิงพรรณนา |
| คำศัพท์แปลตรงจากอังกฤษ | "ภูมิทัศน์ของ...", "ในบริบทของ" ทุกประโยค, "มีบทบาทสำคัญ" (plays a crucial role), "ทำให้มั่นใจว่า" (ensure) | ศัพท์วิชาการไทยที่ใช้จริงในวารสาร |
| ความยาวประโยคเท่ากันหมด | ทุกประโยค 2 บรรทัด | สลับสั้น-ยาว |
| ข้อความไร้ผู้กระทำ ไร้ตัวตนผู้เขียน | ไม่มี "ผู้เขียนเห็นว่า" เลย | บทความวิชาการ มจร ต้องเห็นจุดยืนผู้เขียน ใส่หลังหลักฐาน |
| การอ้างกว้าง ๆ | "นักวิชาการหลายท่านกล่าวว่า", "งานวิจัยจำนวนมากพบว่า" | ระบุชื่อและปี หรือตัด |
| hedging ซ้อน | "อาจจะมีแนวโน้มที่จะ" | เลือกระดับความมั่นใจเดียว |

## สำนวนแปล (ภาษาไทยที่เรียงตามโครงสร้างอังกฤษ)

ผู้อ่านไทยสะดุดกับข้อนี้มากที่สุด แม้ศัพท์จะถูกทุกคำ หลักคือ **ให้ผู้กระทำหรือสิ่งที่ได้รับผลขึ้นต้นประโยค แล้วตามด้วยกริยา** แทนการเอาคำนามนามธรรมเป็นประธาน

| สำนวนแปล | ตัวอย่าง | สำนวนไทย |
|---|---|---|
| นามนามธรรมเป็นประธาน + "ชัดใน/สูงใน" (the effect is concentrated in) | "ผลของใบกำกับภาษีอิเล็กทรอนิกส์ชัดในธุรกิจขนาดเล็ก" | "ผลต่อยอดขายและภาระภาษีที่รายงานเด่นชัดในธุรกิจขนาดเล็ก" (บอกผลลัพธ์ที่งานวัด อย่าเปลี่ยนเป็น "ธุรกิจเห็นผล") |
| "X ชี้ว่า..." / "X แสดงว่า..." ทุกประโยค (X shows/indicates) | "ผู้วิจัย ก ชี้ว่าผล...ชัดใน..." | "หลักฐานของผู้วิจัย ก แสดงว่า..." หรือ "ผู้วิจัย ก พบว่า..." สลับกับประโยคที่ขึ้นต้นด้วยเนื้อความ |
| กรรมวาจก "ถูก..." (passive) | "ถูกรายงานว่าไม่มีอิทธิพล" "ถูกปฏิรูป" | "ไม่พบอิทธิพลอย่างมีนัยสำคัญทางสถิติ" "ได้รับการปฏิรูป" หรือเปลี่ยนเป็นประโยคกรรตุ |
| "ระดับนี้คือการ..." (this level is the...) | "ระดับนี้คือการให้ข้อมูล...ไหลเข้า..." | "ระดับนี้หมายถึงการทำให้ข้อมูล...ไหลเข้า..." หรือขึ้นต้นด้วยผู้กระทำ |
| "ส่งผลทางลบ" (negatively affects) | "การรับรู้ความเสี่ยงส่งผลทางลบ" | "การรับรู้ความเสี่ยงทำให้ความตั้งใจลดลง" (บอกว่าอะไรลดลง) |
| คำนามซ้อนแทนกริยา (nominalization) | "การจัดทำการประเมินผลสุทธิ" | "ประเมินผลสุทธิ" |
| "ซึ่ง" ต่อกันหลายชั้น (which... which...) | "ระบบซึ่ง...ซึ่ง...ซึ่ง..." | ตัดเป็นประโยคใหม่ |
| "อยู่ที่" / "ทำหน้าที่เป็น" แปลจาก lies in / serves as | "เงื่อนไขอยู่ที่ด้านสภาพแวดล้อม" | ใช้ได้บ้าง แต่ถ้าซ้ำ ให้เปลี่ยนเป็น "ขึ้นอยู่กับ" "ต้องอาศัย" |
| "ประโยชน์ของ X น่าจะขึ้นกับ Y" (the benefits of X depend on Y) | "ประโยชน์ของ AI น่าจะขึ้นกับคุณภาพข้อมูล" | "AI จะให้ประโยชน์มากน้อยเพียงใดน่าจะขึ้นอยู่กับคุณภาพข้อมูล" |
| คำย่อหน่วยนับลอย | "ร้อยละ 0.14 ของนิติบุคคล" | "คิดเป็นร้อยละ 0.14 ของนิติบุคคลทั้งหมด" |
| ประโยคไม่มีประธานต่อจากชื่อผู้วิจัย | "...ร้อยละ 65 และเสนอให้รัฐ..." หลังประโยคยาว | "ผู้วิจัยเสนอให้รัฐ..." |

ข้อควรระวังเมื่อแก้สำนวนแปล:
- **อย่าใช้กติกาแบบเหมารวม** "ถูกหักภาษี" "ถูกต้อง" เป็นภาษาไทยปกติ นามนามธรรมเป็นประธานก็ใช้ได้เมื่อชัดเจน แก้เฉพาะที่อ่านแล้วสะดุดหรือกำกวม
- **เปลี่ยนประธานแล้วต้องไม่เปลี่ยนสิ่งที่วัด** เช่น งานที่วัด "ยอดขายและภาระภาษีที่รายงาน" อย่าเขียนใหม่เป็น "ธุรกิจเห็นผล/ได้ประโยชน์" ให้บอกผลลัพธ์ที่วัดจริง ("ผลต่อยอดขาย ยอดซื้อ และภาระภาษีที่รายงานเด่นชัดในธุรกิจขนาดเล็ก")
- **ผลไม่มีนัยสำคัญ ≠ "ไม่มีผล"** เขียน "ไม่พบอิทธิพลอย่างมีนัยสำคัญทางสถิติ (ที่ระดับ ...)" และ R² เขียน "อธิบายความแปรปรวนของ ... ได้ร้อยละ ..."
- **ประโยคกฎหมายห้ามเรียงใหม่จนฐานเปลี่ยน** เช่น "ยกเว้นภาษีเงินได้สำหรับเงินได้จำนวนเท่ากับรายจ่าย" ≠ "ยกเว้นภาษีเป็นจำนวนเท่ากับรายจ่าย" หลังแก้สำนวนให้เทียบทุกประโยคที่มีเงื่อนไขกฎหมายกับตัวบทอีกครั้ง
- **ข้อเสนอสำนวนของผู้ตรวจก็ทำความหมายแคบลงได้** เช่น "ต้นทุนที่กิจการจ่ายจริง" ตัดต้นทุนเวลาภายในออกไปทั้งที่แหล่งนิยามรวมไว้ ("ต้นทุนที่เกิดขึ้นจริงแก่กิจการ" ตรงกว่า) ก่อนรับข้อเสนอสำนวนแต่ละจุด ให้เทียบนิยามในแหล่งและ Abstract ภาษาอังกฤษ
- **ข้ออ้างครอบคลุม** "ยังไม่มีงานใดทดสอบ" → "ในเอกสารที่ทบทวน ผู้เขียนยังไม่พบงานที่ทดสอบ..."
- ศัพท์เดียวกันใช้คำเดียวตลอดเรื่อง (เช่น relative advantage = "ความได้เปรียบเชิงเปรียบเทียบ") และชื่อระดับ/คำย่อในภาพ ตาราง เนื้อหาต้องตรงกัน ห้ามแก้ชื่อเอกสารหรือข้อความยกตรงของผู้อื่น

วิธีตรวจ: อ่านทีละประโยคแล้วถามว่า "ถ้าอาจารย์คนไทยพูดเรื่องนี้ในห้องเรียน จะเรียงคำแบบนี้ไหม" ถ้าไม่ ให้เรียงใหม่ตามลำดับ ผู้กระทำ → กริยา → กรรม → เงื่อนไข ห้ามเปลี่ยนข้อเท็จจริง ตัวเลข การอ้างอิง หรือระดับความมั่นใจ (อาจ/น่าจะ/พบว่า) ระหว่างปรับ

## ขั้นตอน

1. อ่านทั้งส่วน ทำรายการร่องรอยที่พบพร้อมจำนวนครั้ง (เช่น "นอกจากนี้" 9 ครั้ง)
2. แก้ทีละส่วน เทียบก่อน-หลังเฉพาะประโยคที่เปลี่ยน ให้ผู้ใช้ดูตัวอย่าง 3-5 จุด
3. ตรวจว่าไม่มีอ้างอิงหาย ตัวเลขไม่เปลี่ยน ความยาวไม่หดเกิน 10%
4. อ่านออกเสียงในใจ: ถ้าประโยคไหนอ่านแล้วนึกไม่ออกว่าจะพูดกับใคร ให้เขียนใหม่

## ข้อควรระวัง

- ภาษาวิชาการไทยยังต้องเป็นทางการ (ใช้ "มิได้", "หาก", "ย่อม" ได้) อย่าแก้จนเป็นภาษาพูด
- การ "humanize" ไม่ใช่การหลบเครื่องตรวจ AI เป้าหมายคือคุณภาพภาษา และความซ้ำต้องต่ำเพราะเขียนเอง ไม่ใช่เพราะเลี่ยงคำ
