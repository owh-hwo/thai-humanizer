# ร่องรอยภาษา AI และสำนวนแปลในงานเขียนภาษาไทย

เป้าหมายคือให้อ่านเหมือนคนไทยที่รู้เรื่องนั้นเขียนเอง โดย **ไม่เปลี่ยนข้อเท็จจริง ตัวเลข การอ้างอิง ขอบเขต ความสัมพันธ์เชิงเหตุผล หรือระดับความมั่นใจ** เกณฑ์รับงานคือ ความหมายเดิมครบ ความสัมพันธ์ระหว่างข้อความชัด และระดับภาษาเหมาะกับงาน จำนวนร่องรอยที่ลดลงเป็นเพียงข้อมูลประกอบ

ไฟล์นี้ใช้ *หลัง* ร่างเพื่อเก็บตก ส่วนแม่แบบย่อหน้า คลังคำเชื่อม ตารางสำนวนแปลชุดใหญ่ และกลไกภาษาไทยที่ห้ามแก้ อยู่ใน `thai-prose-patterns.md` ตัวเลขความถี่ให้ดูจาก `scripts/thai_style_check.py` ข้อความใน `[ตัวบท]...[/ตัวบท]` และข้อความยกตรงในเครื่องหมายคำพูด ห้ามแก้

ทุกรายการด้านล่างเป็น **จุดตรวจ** การพบรูปคำอย่างเดียวไม่เป็นเหตุให้แก้ ให้อ่านประโยคแล้วถามว่ารูปนั้นทำหน้าที่อะไร และมีรูปที่ตรงกว่าในบริบทนี้ไหม

## ก. ร่องรอยระดับความหมาย (regex จับไม่ได้ แต่ผู้อ่านจับได้)

ชุดนี้สำคัญที่สุด เพราะข้อความที่ลื่นแต่เปลี่ยนความหมายร้ายแรงกว่าข้อความที่ฝืด

| ร่องรอย | ตัวอย่าง | วิธีตรวจและแก้ |
|---|---|---|
| **สรุปคมเกินหลักฐาน** ขอบเขตเลื่อนทีละประโยค | ทบทวนวรรณกรรมบอก "ค่าจ้างไม่ใช่ปัจจัยสำคัญที่สุด" → ย่อหน้าวิเคราะห์บอก "ไม่ได้ออกเพราะเงิน" → บทสรุปบอก "ขึ้นอยู่กับความแน่นอนของเวลามากกว่าจำนวนเงิน" | ทุกประโยคสรุป เทียบกับประโยคหลักฐาน: กลุ่มคน ช่วงเวลา ความแน่นอน และความสัมพันธ์ (สัมพันธ์ / เป็นเหตุ) ยังเท่าเดิมไหม ข้อค้นพบกับข้อสันนิษฐานต้องแยกประโยคกัน: "หลักฐานนี้บอกได้เพียงว่าค่าจ้างไม่ใช่ปัจจัยสำคัญที่สุด ส่วนปัจจัยใดสำคัญกว่า ผู้เขียนเสนอเป็นข้อสันนิษฐานว่า..." การติดป้าย "ผู้เขียนเสนอ" ไม่ได้ทำให้ข้อสรุปที่เกินหลักฐานกลายเป็นข้อค้นพบ |
| **คู่ตรงข้ามเด็ดขาด** "ไม่ใช่ X แต่ Y" / "อยู่ที่ระบบ ไม่ใช่ที่ตัวบุคคล" | "ปัญหาจึงอยู่ที่ระบบวางแผน ไม่ใช่ที่ตัวบุคคล" ทั้งที่หลักฐานบอกเพียงว่าระบบก็มีส่วน | รูปนี้เป็นไทยปกติ แต่มันตัด X ออกจากกลุ่มสาเหตุทั้งหมด ตรวจว่าหลักฐานรองรับการตัดนั้นไหม ถ้าไม่ เขียน "การแก้ปัญหาต้องครอบคลุมระบบวางแผนด้วย" |
| **คำอ้างย้อนกำกวม** "ข้อนี้ / สิ่งนี้ / ดังกล่าว / ซึ่ง / มาตรการนี้" | "ข้อนี้ผู้เขียนเห็นต่าง" หลังย่อหน้าที่มีสามประเด็น; "มาตรการนี้" หลังเสนอสองมาตรการ; "โรงงานแปรรูปอาหารและนิคมอุตสาหกรรม ซึ่งความผันผวน..." (ซึ่งขยายอะไร) | แทนคำอ้างย้อนด้วยนามเต็ม ถ้าแทนได้มากกว่าหนึ่งทาง ให้เขียนนามเต็มหรือระบุประเด็น ("ในด้านแนวทางแก้ไข ผู้เขียนเห็นต่าง...") |
| **หลบคำซ้ำด้วยคำใกล้เคียงจนสิ่งที่อ้างเปลี่ยน** | "รากอัดแน่น" กลายเป็น "รากล้น"; "ค่าจ้าง" กลายเป็น "จำนวนเงิน"; "พนักงานฝ่ายผลิตใหม่" "พนักงานอายุต่ำกว่า 30 ปี" "พนักงานรุ่นใหม่" ใช้สลับกันเหมือนเป็นกลุ่มเดียว | คำหลักที่เป็นแนวคิด ตัวแปร หรือกลุ่มตัวอย่าง ใช้คำเดียวตลอดเรื่อง ซ้ำได้ ไม่ต้องหลบ |
| **ย่อจนความสัมพันธ์หาย** | "อัตราอยู่ครบปี" (อยู่ที่ไหน) "หลังออก" (ออกจากอะไร) "ย้ายกระถาง" (ย้ายอะไรไปไหน) "มีคนบอก" (บอกอะไร) | ละได้เมื่อผู้อ่านกู้คืนได้ทางเดียว ถ้าเดาได้คร่าว ๆ ยังไม่พอ ต้องเติม |
| **คำเชื่อมอ้างความสัมพันธ์ที่ยังไม่ได้ปู** | "ปุ๋ยก็เรื่องเดียวกัน" (เหมือนกันตรงไหน) "จึง" หน้าข้อสรุปที่ไม่มีขั้นกลาง | ลองตัดคำเชื่อมออก ถ้าผู้อ่านยังเห็นความสัมพันธ์จากเนื้อหา คำเชื่อมใช้ได้ ถ้าไม่เห็น ต้องเพิ่มคำอธิบาย ไม่ใช่เพิ่มคำเชื่อม |
| **สมาชิกรายการต่างประเภท รับกริยาเดียว** | "นัดเรียน นัดหมอ หรือการดูแลคนในบ้านล้มทั้งหมด" | แจกกริยาให้แต่ละสมาชิก ("ต้องเลื่อนเวลาเรียน เลื่อนนัดพบแพทย์ หรือปรับแผนดูแล...") |
| **กริยากับนามไม่เข้าคู่** | "แก้ไขความท้าทาย" "บรรลุความต้องการ" "วัดเหตุผล" | ใช้คู่ที่ไทยใช้จริง: รับมือกับความท้าทาย / ตอบสนองความต้องการ / สอบถามเหตุผล |
| **แต่งเสียงคนขึ้นเอง** | "ผมเองใส่แบบนี้อยู่ปีกว่าก่อนจะมีคนบอก" ที่ผู้ใช้ไม่ได้ให้มา; ภาพเปรียบ "รับหน้าแทนระบบ" ที่ไม่บอกภาระจริง | ใช้บุรุษที่หนึ่งและประสบการณ์เฉพาะที่เจ้าของงานให้มา ถ้าไม่มี อย่าเติม หลังอ่านประโยคที่ตั้งใจให้มีบุคลิก ถามว่าผู้อ่านรู้อะไรเพิ่ม ถ้าได้แค่ความรู้สึกว่า "มีคนเล่า" ให้ตัด |
| **ระดับภาษาแกว่ง** ในชิ้นเดียว | บทความวารสารใช้ "ควบคุมตัวแปร" "ทดสอบเชิงประจักษ์" สลับกับ "คนที่ไปแล้ว" "ตามสัมภาษณ์" "แล้วค่อย" "ต้องทน" "แกว่งตัวแรง" | ตรวจเป็นชุด (ตารางวิชาการ/ทั่วไปใน `thai-prose-patterns.md`) คำเรียกคน กริยาเชิงสนทนา คำตัดสินทางอารมณ์ และภาพเปรียบ ต้องอยู่ระดับเดียวกับศัพท์วิชาการในชิ้นนั้น บทความเว็บไม่ต้องยกขึ้นเป็นวิชาการ |
| **หัวข้อไม่ตรงเนื้อหา** | "สิ่งที่งานวิจัยไทยบอกไว้แล้ว" แต่ใต้หัวข้อมีงานต่างประเทศ; "ไม่เพิ่มต้นทุนมาก" ในหัวข้อ แต่เนื้อหาบอก "ไม่ต้องเพิ่มค่าจ้าง" | เปลี่ยนหัวข้อหรือย้ายย่อหน้า ค่าจ้างเป็นต้นทุนชนิดหนึ่ง ไม่ใช้แทนกัน |
| **ประโยคบอกข้อจำกัดที่อ่านได้สองทาง** | "ผู้เขียนไม่สามารถตรวจสอบได้จากฉบับเต็ม" (เข้าถึงไม่ได้ หรืออ่านแล้วไม่พอ) | เลือกตามความจริง: "ผู้เขียนเข้าถึงได้เฉพาะบทคัดย่อ จึงยัง...ไม่ได้" หรือ "ฉบับเต็มให้ข้อมูลไม่พอสำหรับ..." |
| **ขอบเขตปฏิเสธและปริมาณ** | "ผู้ใช้ทั้งหมดไม่ยอมรับ" (ไม่มีใคร หรือไม่ใช่ทุกคน); "ยังไม่พบผล" กลายเป็น "ไม่มีผล" | ตรวจ "เฉพาะ เพียง ยัง ทั้งหมด เท่านั้น" ทุกตัวหลังเรียงประโยคใหม่ |

## ข. ร่องรอยระดับคำและโครงสร้าง (สคริปต์นับได้ แต่ต้องอ่านก่อนแก้)

| ร่องรอย | ตัวอย่าง | แก้เป็น |
|---|---|---|
| เปิดเรื่องแบบสำเร็จรูป | "ในยุคปัจจุบันที่โลกเปลี่ยนแปลงอย่างรวดเร็ว..." "ในโลกยุคดิจิทัล..." | เปิดด้วยข้อเท็จจริงเจาะจง เหตุการณ์ สถิติ ปัญหาทางทฤษฎี หรือข้อถกเถียง (แม่แบบ ก) |
| ไม่เพียงแต่...แต่ยัง... / มิใช่...หากแต่... ใช้ถี่ | ทุก 2-3 ย่อหน้า | รูปจัดฉาก ใช้เมื่อต้องการแย้งความเข้าใจผิดจริง ที่เหลือเขียนตรง ๆ |
| ไตรภาคบังคับ | "ทั้งด้านเศรษฐกิจ สังคม และสิ่งแวดล้อม" ทุกที่ | แจกแจงตามจำนวนจริง 2 หรือ 4 ก็ได้ |
| คำขยายเกินจริง | อย่างยิ่ง, อย่างมีนัยสำคัญ (ที่ไม่ใช่สถิติ), อย่างลึกซึ้ง, อย่างก้าวกระโดด, ปฏิวัติวงการ, กุญแจสำคัญ, หัวใจสำคัญ, ขับเคลื่อน (ซ้ำ ๆ) | ตัดทิ้ง หรือใส่ตัวเลข/หลักฐานแทน |
| "มีนัยสำคัญ" กำกวมระหว่างสถิติกับความสำคัญเชิงเนื้อหา | "ปัจจัยด้านผู้บริหารมีนัยสำคัญต่อความสำเร็จ" | ถ้าหมายถึงผลทดสอบ เขียน "มีนัยสำคัญทางสถิติ" ตามต้นฉบับ ถ้าหมายถึงความสำคัญเชิงเนื้อหา บอกว่าสำคัญต่อข้อสรุปหรือการตัดสินใจอย่างไร อย่าเติมความหมายทางสถิติให้ข้อความเดิม |
| คำเชื่อมซ้ำต้นย่อหน้า | "นอกจากนี้" "อย่างไรก็ตาม" "ดังนั้น" "ทั้งนี้" ขึ้นต้นหลายย่อหน้าติดกัน | ให้ประโยคหลักนำย่อหน้าเอง (แม่แบบ ฉ ช) ไม่สลับเป็นคำพ้องเพื่อหลบจำนวน |
| ประโยคปิดสรุปทุกย่อหน้า | "...ซึ่งสะท้อนให้เห็นถึงความสำคัญของ..." "...จึงเป็นสิ่งที่ไม่อาจมองข้ามได้" | ปิดด้วยข้อสรุปเฉพาะของย่อหน้านั้น หรือไม่ต้องปิด |
| คำนามนามธรรมซ้อนจนหาคำหลักไม่พบ | "การดำเนินการในการพัฒนาการบริหารจัดการ" | "พัฒนาการบริหาร" คงรูปนามเมื่อเป็นชื่อแนวคิดหรือตัวแปร |
| ขีดแทรก em dash | "องค์กรที่ปรับตัวได้ — องค์กรที่ปรับตัวไม่ได้..." | วารสารไทยส่วนใหญ่ไม่ใช้ขีดแทรก เปลี่ยนเป็นจุลภาค วงเล็บ หรือแยกประโยค ขีดบอกช่วง "หน้า 15–20" คงไว้ |
| บูลเล็ตหั่นร้อยแก้ว (ทุกประเภทงาน) | ทุกข้อขึ้นต้นด้วยป้ายตัวหนา + ทวิภาค ("**ความคุ้มค่า:** ..."); ข้อที่ขึ้นต้นด้วย "ดังนั้น / จึง / แต่ / นอกจากนี้" ซึ่งต่อจากข้อก่อน; ข้อละหลายประโยค; รายการ 1-2 ข้อ; ตัวหนากลางย่อหน้าวิชาการ | ใช้เกณฑ์ "รายการหรือร้อยแก้ว" ใน `thai-prose-patterns.md` เหตุผลต่อเนื่อง เปรียบเทียบ อภิปราย เขียนเป็นร้อยแก้ว ขั้นตอน เกณฑ์ ตัวเลือก งานที่มีกำหนดส่ง คงเป็นรายการ ตอนรวมเป็นย่อหน้าห้ามเติมความสัมพันธ์เชิงเหตุผลที่รายการเดิมไม่ได้บอก |
| ภาษาขายของ/ปลุกใจ | "ก้าวสู่อนาคตที่ยั่งยืน", "ปลดล็อกศักยภาพ", "เปิดประตูสู่" | ภาษาเป็นกลาง เชิงพรรณนา |
| คำศัพท์แปลตรงจากอังกฤษ | "ภูมิทัศน์ของ...", "ในบริบทของ" ทุกประโยค, "มีบทบาทสำคัญ", "ทำให้มั่นใจว่า" | ศัพท์ที่ใช้จริงในวารสาร ("ภูมิทัศน์" ใช้ตรงความหมายในภูมิสถาปัตยกรรมได้) |
| ประโยคภาระการอ่านสูงเท่ากันหมด | ทุกประโยคมีเงื่อนไขซ้อนสามชั้น | แบ่งเมื่อเปลี่ยนประเด็น เปลี่ยนผู้กระทำ หรือผู้อ่านต้องย้อนหาคำหลัก ไม่ใช่สลับสั้น-ยาวเป็นสูตร |
| ไม่แยกผล หลักฐาน การตีความ ข้อเสนอ | ย่อหน้าวิเคราะห์อ่านแล้วไม่รู้ว่าอะไรเป็นผลของงานที่อ้าง อะไรเป็นความเห็นผู้เขียน | ระบุเจ้าของความเห็นเมื่อต้องแยก ("ผู้เขียนเห็นว่า") ไม่ต้องมีทุกย่อหน้า และไม่ถือว่าไม่มีสรรพนามผู้เขียนเท่ากับไม่มีจุดยืน |
| การอ้างกว้าง ๆ | "นักวิชาการหลายท่านกล่าวว่า", "งานวิจัยจำนวนมากพบว่า" | ระบุชื่อและปี หรือตัด |
| ซ้อนคำมิติเดียวกัน | "อาจจะมีแนวโน้มที่จะ" | เลือกคำเดียวในมิติความเป็นไปได้ "บ่งชี้ว่า...อาจ..." ไม่ซ้อนเพราะคนละมิติ |
| "มัน" ไร้สิ่งอ้างถึงในงานวิชาการ | "มันเป็นเรื่องยากที่จะประเมิน" | "การประเมิน...ทำได้ยาก" |
| "ของคุณ" ทุกนาม | "เปิดบัญชีของคุณ ตรวจสอบข้อมูลของคุณ ก่อนส่งคำขอของคุณ" | ตัดที่ไม่ต้องแยกเจ้าของ |
| "ที่ซึ่ง" กับสิ่งที่ไม่ใช่สถานที่ | "ขั้นตอนที่ซึ่งผู้ใช้ต้องยืนยันตัวตน" | "ในขั้นตอนนี้ ผู้ใช้ต้องยืนยันตัวตน" ("พื้นที่ซึ่งประสบภัย" เป็นไทยปกติ สคริปต์ไม่นับรายการนี้ ต้องอ่านเอง) |
| "เป็น + นามซ้ำ + ที่" | "ระบบนี้เป็นระบบที่ใช้งานง่าย" | "ระบบนี้ใช้งานง่าย" |
| "เมื่อพูดถึง(เรื่องของ)..." เปิดหัวข้อ | "เมื่อพูดถึงเรื่องของค่าใช้จ่าย ระบบนี้..." | เข้าเรื่องเลย |
| "สิ่งนี้ / สิ่งดังกล่าว" อ้างกลับทั้งย่อหน้า | "บริษัทลดพนักงานและเพิ่มงบระบบ สิ่งนี้ทำให้..." | เขียนนามเต็ม "การลดพนักงานและเพิ่มงบระบบทำให้..." |
| "มาพร้อมกับ" แทนทุกความสัมพันธ์ | "การสมัครสมาชิกมาพร้อมกับค่าธรรมเนียม" | "ผู้สมัครต้องจ่ายค่าธรรมเนียม" |
| "ภายใต้การ... / บนพื้นฐานของ / ผ่านทางการ" | "ภายใต้การใช้ระบบนี้ ผู้ใช้..." | "เมื่อใช้ระบบนี้ ผู้ใช้..." คง "ภายใต้" กับกฎหมายหรือกรอบทฤษฎี |
| "ตัดสินใจอย่างมีข้อมูล" | informed decision | "มีข้อมูลประกอบการตัดสินใจ" |
| ถ้อยคำของผู้ช่วยหลุดในตัวบท | "หากคุณต้องการ ฉันสามารถปรับข้อความนี้..." "ต่อไปนี้คือฉบับ..." "หวังว่าบทความนี้..." | ตัดออกทั้งหมด จบที่เนื้อหา |

## ค. สำนวนแปล (ภาษาไทยที่เรียงตามโครงสร้างอังกฤษ)

ผู้อ่านไทยสะดุดกับข้อนี้มากที่สุด แม้ศัพท์จะถูกทุกคำ หลักคือ **ขึ้นต้นประโยคด้วยสิ่งที่กำลังพูดถึง** (ผู้กระทำ สิ่งที่ได้รับผล เวลา หรือเงื่อนไข) ไม่ใช่นามนามธรรมที่กำกวม ทุกฉบับ "แก้เป็น" ด้านล่างมีเงื่อนไขว่าใช้ได้เมื่อต้นฉบับหมายความอย่างนั้นจริง

| สำนวนแปล | ตัวอย่าง | สำนวนไทย และเงื่อนไข |
|---|---|---|
| "ผลของ X ชัดใน Y" (the effect is concentrated in) | "ผลของใบกำกับภาษีอิเล็กทรอนิกส์ชัดในธุรกิจขนาดเล็ก" | "ในกลุ่มธุรกิจขนาดเล็ก งานรายงานว่า [ยอดขายที่รายงาน / ภาระภาษีที่รายงาน] [เพิ่มขึ้น/ลดลง ขนาดตามแหล่ง]" บอกตัวแปรที่งานวัดจริงพร้อมทิศทางหรือขนาดตามแหล่ง ถ้าแหล่งไม่บอกทิศทาง จึงใช้ "ผลต่อ...ปรากฏชัดกว่า..." ห้ามเขียนเป็น "ธุรกิจเห็นผล" |
| "X ชี้ว่า..." ทุกประโยค (X shows) | "ผู้วิจัย ก ชี้ว่าผล...ชัดใน..." | สลับระหว่าง "ก (2567) พบว่า..." กับรูปที่เนื้อความนำแล้ววงเล็บอ้างอิงท้าย ไม่ต้องใช้ "หลักฐานของผู้วิจัย ก แสดงว่า" เป็นแม่แบบใหม่ |
| กรรมวาจก "ถูก..." ที่ไม่ใช่หัวเรื่อง | "ถูกรายงานว่าไม่มีอิทธิพล" | "งานดังกล่าวรายงานว่า X ไม่มีอิทธิพลต่อ Y" แล้วตรวจแหล่งว่าเป็น "ไม่มีอิทธิพล" หรือ "ไม่พบอิทธิพลอย่างมีนัยสำคัญทางสถิติ" ต้องแก้ด้วยหลักฐาน ไม่ใช่ตารางแทนคำ "ถูกปฏิรูป" คงได้เมื่อระบบเป็นหัวเรื่อง ถ้ารู้ผู้กระทำและต้องการเน้น จึงเขียน "[หน่วยงาน] ปฏิรูป..." |
| "ระดับนี้คือการ..." (this level is the...) | "ระดับนี้คือการให้ข้อมูล...ไหลเข้า..." | ถ้านิยาม: "ระดับนี้หมายถึงการเปิดให้ข้อมูล...เข้าสู่..." ถ้าอธิบายการทำงาน: "ในระดับนี้ [ผู้กระทำตามต้นฉบับ] ส่งข้อมูล...เข้าสู่..." |
| "ส่งผลทางลบ" (negatively affects) | "การรับรู้ความเสี่ยงส่งผลทางลบ" | ถ้าต้นฉบับรายงานความสัมพันธ์: "การรับรู้ความเสี่ยงที่สูงขึ้นสัมพันธ์กับความตั้งใจใช้ที่ลดลง" ถ้าต้นฉบับรองรับเหตุและผล จึงใช้ "ทำให้...ลดลง" ตัวแปรตามต้องเป็นตัวที่งานวัดจริง |
| คำนามซ้อนแทนกริยา | "การจัดทำการประเมินผลสุทธิ" | "ประเมินผลสุทธิ" |
| "ซึ่ง" ต่อกันหลายชั้น | "ระบบซึ่ง...ซึ่ง...ซึ่ง..." | ตัดเป็นประโยคใหม่ |
| "อยู่ที่" / "ทำหน้าที่เป็น" ซ้ำ (lies in / serves as) | "เงื่อนไขอยู่ที่ด้านสภาพแวดล้อม" | ใช้ได้บ้าง ถ้าซ้ำ เปลี่ยนเป็น "ขึ้นอยู่กับ" "ต้องอาศัย" |
| สัดส่วนไม่บอกฐาน | "ร้อยละ 0.14 ของนิติบุคคล" | "นิติบุคคลที่[เข้าเงื่อนไข]คิดเป็นร้อยละ 0.14 ของ[ฐานตามต้นฉบับ]" ห้ามเติม "ทั้งหมด" เอง เพราะเปลี่ยนฐานจากกลุ่มตัวอย่างเป็นทั้งประเทศได้ |
| ประโยคไม่มีประธานต่อจากชื่อผู้วิจัยหลังข้อความแทรกยาว | "...ร้อยละ 65 และเสนอให้รัฐ..." | "ผู้วิจัยเสนอให้รัฐ..." |
| "จากบทคัดย่อของงาน X ซึ่ง... [นามวลี] สัมพันธ์กับ..." | ผู้อ่านรอ "พบว่า" แล้วไม่ได้รับ | "X (2023) สำรวจ... บทคัดย่อรายงานว่า..." (แม่แบบ ค) |

ประโยคที่มีนามนามธรรมเป็นประธานแต่ชัด เช่น "ประโยชน์ของ AI น่าจะขึ้นอยู่กับคุณภาพข้อมูล" ไม่ต้องแก้ การขยายเป็น "AI จะให้ประโยชน์มากน้อยเพียงใดน่าจะขึ้นอยู่กับ..." ทำให้หนักขึ้นโดยไม่ได้อะไร

ข้อควรระวังเมื่อแก้สำนวนแปล:
- **อย่าใช้กติกาแบบเหมารวม** "ถูกหักภาษี" "ถูกต้อง" "ถูกเลือก" "ถูกบังคับ" เป็นภาษาไทยปกติ นามนามธรรมเป็นประธานใช้ได้เมื่อชัดเจน "แม้...ก็ตาม แต่..." เป็นไทยปกติ แก้เฉพาะที่อ่านแล้วสะดุดหรือกำกวม
- **"ได้รับการ..." ไม่ใช่คำแทน "ถูก..."** ทั้งคู่เป็นกรรมวาจก เลือกตามหัวเรื่องและน้ำเสียง และห้ามแต่งผู้กระทำขึ้นเพื่อหลบกรรมวาจก
- **เปลี่ยนประธานแล้วต้องไม่เปลี่ยนสิ่งที่วัด** งานที่วัด "ยอดขายและภาระภาษีที่รายงาน" อย่าเขียนใหม่เป็น "ธุรกิจเห็นผล/ได้ประโยชน์"
- **ผลไม่มีนัยสำคัญ ≠ "ไม่มีผล"** เขียน "ไม่พบอิทธิพลอย่างมีนัยสำคัญทางสถิติ (ที่ระดับ ...)" เมื่อแหล่งรายงานอย่างนั้น และ R² เขียน "อธิบายความแปรปรวนของ ... ได้ร้อยละ ..."
- **"สัมพันธ์กับ" ≠ "ทำให้"** อย่ายกระดับความสัมพันธ์เป็นเหตุและผลขณะเกลา
- **ประโยคกฎหมายห้ามเรียงใหม่จนฐานเปลี่ยน** "ยกเว้นภาษีเงินได้สำหรับเงินได้จำนวนเท่ากับรายจ่าย" ≠ "ยกเว้นภาษีเป็นจำนวนเท่ากับรายจ่าย" หลังแก้สำนวนให้เทียบทุกประโยคที่มีเงื่อนไขกฎหมายกับตัวบทอีกครั้ง
- **ข้อเสนอสำนวนของผู้ตรวจก็ทำความหมายแคบลงได้** "ต้นทุนที่กิจการจ่ายจริง" ตัดต้นทุนเวลาภายในออกทั้งที่แหล่งนิยามรวมไว้ ("ต้นทุนที่เกิดขึ้นจริงแก่กิจการ" ตรงกว่า) ก่อนรับข้อเสนอแต่ละจุด เทียบนิยามในแหล่ง
- **อย่าละลายรายการที่ถูกต้องเป็นย่อหน้า** ขั้นตอน เกณฑ์ หรือเอกสารที่ต้องเตรียม ที่ผู้อ่านไล่ตรวจทีละข้อ อ่านยากขึ้นเมื่อรวมเป็นย่อหน้าเดียว การมีบูลเล็ตไม่ใช่ร่องรอย AI ในตัวเอง ร่องรอยคือบูลเล็ตที่ตัดเหตุผลขาดจากกัน
- **ข้ออ้างครอบคลุม** "ยังไม่มีงานใดทดสอบ" → "ในเอกสารที่ทบทวน ผู้เขียนยังไม่พบงานที่ทดสอบ..."
- ศัพท์เดียวกันใช้คำเดียวตลอดเรื่อง และชื่อระดับ/คำย่อในภาพ ตาราง เนื้อหาต้องตรงกัน ห้ามแก้ชื่อเอกสารหรือข้อความยกตรงของผู้อื่น

วิธีตรวจ: อ่านทีละประโยค ถามสองข้อแยกกัน (1) คำเกาะกลุ่มถูกไหม อ่านแล้วกำกวมไหม (2) ระดับภาษาตรงกับประเภทงานไหม สำหรับบทความวารสารถามว่า "อาจารย์ไทยเขียนลงวารสารแบบนี้ไหม" สำหรับบทความเว็บถามว่า "คนที่รู้เรื่องนี้เล่าให้ผู้อ่านฟังแบบนี้ไหม" ถ้าไม่ ให้เรียงใหม่ตามหัวเรื่อง และห้ามเปลี่ยนข้อเท็จจริง ตัวเลข การอ้างอิง ขอบเขต หรือระดับความมั่นใจระหว่างปรับ

## ขั้นตอน

1. อ่านทั้งส่วน ทำรายการร่องรอยที่พบพร้อมจำนวนครั้ง (รวมผลจากสคริปต์) และทำรายการ **คำหลัก** (แนวคิด ตัวแปร กลุ่มตัวอย่าง) ที่ต้องใช้คำเดียวตลอด
2. แก้ทีละส่วน เขียนประโยคใหม่จากใจความ ไม่ใช่แทนคำทีละคำ เทียบก่อน-หลังเฉพาะประโยคที่เปลี่ยน ให้ผู้ใช้ดูตัวอย่าง 3-5 จุด ฉบับเกลาสำนวนต้องไม่เปลี่ยนน้ำหนักข้อความ ถ้าพบข้อความที่เกินหลักฐาน ให้แยกเป็น "ข้อเสนอแก้สาระ" พร้อมเหตุผล ส่งคู่กับฉบับเกลา ไม่แก้เงียบ ๆ แล้วแจ้งทีหลัง
3. ตรวจความหมายเดิมครบ (ชุด ก ด้านบน): ไม่มีอ้างอิงหาย ตัวเลขไม่เปลี่ยน ขอบเขตและความสัมพันธ์ไม่เลื่อน คำอ้างย้อนแทนด้วยนามเต็มได้ทางเดียว ความยาวที่หดต้องมาจากตัดคำเปล่า ไม่ใช่ตัดเงื่อนไข (หดเกินร้อยละ 10 เป็นสัญญาณให้ตรวจ ไม่ใช่ข้อห้าม)
4. ตรวจกลไกภาษาไทยที่มักพังหลังแก้ (ท้าย `thai-prose-patterns.md`): เว้นวรรค ไม้ยมก คำช่วยกริยา ลักษณนาม ขอบเขตปฏิเสธ
5. ตรวจรูปแบบเป็นรอบสุดท้าย แยกกฎภาษาออกจากรูปแบบสำนักพิมพ์: ช่องว่างหน้า-หลังทวิภาค ตัวเลข ร้อยละ รายการอ้างอิง ตามคู่มือของงาน

## ข้อควรระวัง

- ภาษาวิชาการไทยยังต้องเป็นทางการ (ใช้ "มิได้", "หาก", "ย่อม" ได้) อย่าแก้จนเป็นภาษาพูด และอย่าแก้บทความเว็บจนเป็นภาษาราชการ
- การ "humanize" ไม่ใช่การหลบเครื่องตรวจ AI เป้าหมายคือคุณภาพภาษา และความซ้ำต้องต่ำเพราะเขียนเอง ไม่ใช่เพราะเลี่ยงคำ
- เกณฑ์ความถี่ในสคริปต์เป็นค่าทดลองที่ปรับจากตัวอย่างบทความวารสารจำนวนน้อย ใช้เป็นสัญญาณเรียกตรวจ ไม่ใช่เพดานถูกผิด ข้อความสั้น (อีเมล 100 คำ) ให้ดูจำนวนจริงและตำแหน่งซ้ำ ไม่ดูอัตราต่อ 1,000 คำ
