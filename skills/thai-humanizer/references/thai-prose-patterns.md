# แบบแผนร้อยแก้ววิชาการไทย (เขียนให้เหมือนนักวิชาการไทยเขียนเอง)

`thai-humanizer.md` บอกว่า *อย่า* เขียนแบบใด ไฟล์นี้บอกว่า *ให้* เขียนแบบใด ใช้ตอนร่าง ก่อนที่สำนวน AI หรือสำนวนแปลจะติดมากับข้อความ แก้ทีหลังยากกว่ามาก แบบแผนด้านล่างสกัดจากบทความวิชาการที่ตีพิมพ์ในวารสาร TCI สายสังคมศาสตร์และบริหารธุรกิจ ตัวอย่างทุกประโยคแต่งขึ้นเพื่อแสดงรูปประโยค ไม่ใช่ข้อเท็จจริง

## หลักใหญ่ 4 ข้อ

1. **เขียนจากโน้ตภาษาไทย ไม่ใช่จากประโยคภาษาอังกฤษ** ก่อนเขียนย่อหน้าที่อ้างงานต่างประเทศ ให้สรุปงานนั้นเป็นโน้ตไทยสั้น ๆ ในรูป "ใคร ศึกษาอะไร กับใคร/ข้อมูลอะไร วัดอะไร ได้ผลอย่างไร" (เก็บใน `key_point` ของ refs.json) แล้วปิดบทคัดย่อภาษาอังกฤษ เขียนจากโน้ต เสร็จแล้วค่อยเปิดต้นฉบับกลับมาเทียบตัวเลขและระดับความมั่นใจ ถ้าเขียนโดยมองประโยคอังกฤษ ลำดับคำจะตามอังกฤษเสมอ
2. **ประโยคไทยเดินด้วยผู้กระทำและกริยา** ผู้กระทำ (ผู้วิจัย กิจการ รัฐ ระบบ) → กริยา → กรรม → เงื่อนไข นามนามธรรมเป็นประธานได้เมื่อชัดเจน แต่ไม่ควรเป็นประธานติดกันหลายประโยค
3. **ย่อหน้ามีตรรกะเดียว: ข้อความหลัก → หลักฐาน → ความเห็นผู้เขียน** ประโยคแรกบอกว่าย่อหน้านี้จะพูดอะไร ตรงกลางคือหลักฐานพร้อมอ้างอิง ท้ายย่อหน้าคือสิ่งที่ผู้เขียนสรุปหรือเห็นต่าง ไม่ต้องมีประโยคปิดสวย ๆ ถ้าไม่มีอะไรจะสรุป
4. **เสียงของผู้เขียนต้องได้ยิน** บทความวิชาการไทยคาดหวังจุดยืน ใช้ "ผู้เขียนเห็นว่า" "ในมุมมองของผู้เขียน" "ผู้เขียนตั้งข้อสังเกตว่า" "ผู้เขียนเสนอว่า" หลังหลักฐาน ไม่ใช่ก่อน และใช้พอประมาณ (ราว 1 ครั้งต่อ 2-3 ย่อหน้าในส่วนวิเคราะห์)

## แม่แบบย่อหน้า

### ก. เปิดบทนำด้วยข้อเท็จจริงเจาะจง

เปิดด้วยเหตุการณ์ วันที่ ตัวเลข หรือการเปลี่ยนแปลงเชิงนโยบายที่ผู้อ่านตรวจสอบได้ แล้วค่อยบอกว่าเหตุการณ์นั้นสะท้อนปัญหาอะไร

> เมื่อวันที่ 1 มกราคม 2569 หน่วยงาน ก เริ่มบังคับใช้ระเบียบใหม่ที่กำหนดให้กิจการทุกขนาดต้องยื่นรายงานผ่านระบบอิเล็กทรอนิกส์ (ชื่อหน่วยงาน, 2569) ภายในสามเดือนแรกมีกิจการยื่นผ่านระบบเพียงร้อยละ 12 ของกิจการที่มีหน้าที่ (ชื่อผู้วิจัย, 2569) ช่องว่างระหว่างข้อกำหนดกับการปฏิบัติจริงนี้คือปัญหาที่บทความนี้ต้องการอธิบาย

ห้าม: "ในยุคปัจจุบันที่เทคโนโลยีเปลี่ยนแปลงอย่างรวดเร็ว..." "ในโลกยุคดิจิทัล..." "เป็นที่ทราบกันดีว่า..."

### ข. เกริ่นงานที่อ้าง (บทความวิจัยเชิงประจักษ์)

รูปที่วารสารไทยใช้บ่อยที่สุดคือ **ผู้วิจัย (ปี) + กริยาศึกษา + กลุ่ม/ข้อมูล + "พบว่า" + ผลที่วัด** แล้วตามด้วยการตีความของผู้เขียนในประโยคถัดไป ถ้ามี

> ชื่อผู้วิจัย (2567) ศึกษาผู้ประกอบการรายย่อยในจังหวัด ข จำนวน 200 ราย พบว่า กิจการที่ใช้ระบบบัญชีออนไลน์ใช้เวลาจัดทำรายงานภาษีต่อเดือนน้อยกว่ากิจการที่ไม่ใช้ราว 6 ชั่วโมง แต่ความแตกต่างนี้พบเฉพาะกิจการที่มีพนักงานบัญชีประจำ

กริยาที่ใช้สลับกันได้ตามสิ่งที่งานทำจริง: ศึกษา / สำรวจ / วิเคราะห์ข้อมูล... / ทดสอบ / เปรียบเทียบ / ทบทวนวรรณกรรม / รายงานว่า / อธิบายว่า / ระบุว่า / เสนอว่า / ตั้งข้อสังเกตว่า
- "พบว่า" ใช้กับผลที่งานนั้นทดสอบหรือวัดจริง
- "ระบุว่า / อธิบายว่า / เสนอว่า" ใช้กับความเห็นหรือข้อเสนอของผู้วิจัย
- "รายงานว่า" ใช้กับตัวเลขหรือข้อมูลที่งานนั้นนำมาแสดง

อย่าเริ่มทุกประโยคด้วยชื่อผู้วิจัย สลับกับรูปที่เนื้อความนำแล้ววงเล็บอ้างอิงท้ายประโยค

> กิจการขนาดเล็กมีสัดส่วนต้นทุนการปฏิบัติตามกฎหมายต่อยอดขายสูงกว่ากิจการขนาดใหญ่หลายเท่า (ชื่อผู้วิจัย et al., 2015)

### ค. อ้างงานที่อ่านได้เพียงบทคัดย่อ

บอกระดับหลักฐานด้วยถ้อยคำ ไม่ใช่ซ่อน

> จากบทคัดย่อของงาน ชื่อผู้วิจัย (2023) ซึ่งสำรวจกิจการ 300 แห่งในประเทศ ค ปัจจัยด้านการสนับสนุนจากผู้บริหารสัมพันธ์กับการนำระบบมาใช้ ส่วนรายละเอียดของขนาดอิทธิพล ผู้เขียนไม่สามารถตรวจสอบได้จากฉบับเต็ม

### ง. วางงานสองชิ้นเทียบกัน

ภาษาไทยไม่ต้องใช้ "ในขณะที่... อย่างไรก็ตาม..." ทุกครั้ง ให้บอกตรง ๆ ว่างานสองชิ้นวัดคนละอย่างหรือได้ผลต่างกัน แล้วบอกว่าเทียบกันได้แค่ไหน

> งานของ ก (2566) และ ข (2567) ให้ผลต่างกัน งานแรกวัดความตั้งใจใช้ระบบของผู้ทำบัญชี ส่วนงานหลังวัดเวลาที่กิจการใช้จริงหลังนำระบบมาใช้ ทั้งสองงานจึงไม่ได้ขัดกัน แต่ร่วมกันชี้ว่าความตั้งใจใช้กับผลที่เกิดจริงเป็นคนละเรื่อง

คำเชื่อมเปรียบเทียบที่ไทยใช้จริง: ส่วน / ขณะที่ / กลับ / ต่างจาก / เทียบกับ / ในทางกลับกัน (ใช้ไม่บ่อย)

### จ. ใส่จุดยืนผู้เขียนหลังหลักฐาน

> ผู้เขียนเห็นว่าผลทั้งสองชิ้นนี้ยังไม่พอจะสรุปว่าระบบช่วยลดต้นทุน เพราะไม่มีงานใดวัดต้นทุนที่เพิ่มขึ้นจากค่าระบบและเวลาฝึกอบรมควบคู่กัน

รูปอื่น: "ในมุมมองของผู้เขียน ..." / "ผู้เขียนตั้งข้อสังเกตว่า ..." / "ข้อนี้ผู้เขียนเห็นต่างจาก ก (2566) ตรงที่ ..." / "ผู้เขียนอนุมานจากหลักฐานข้างต้นว่า ..." / "ผู้เขียนเสนอเป็นข้อสันนิษฐานว่า ..."

### ฉ. ย่อหน้าขยายประเด็น (แทน "นอกจากนี้")

เปิดด้วยสิ่งที่จะเพิ่ม ไม่ใช่คำเชื่อมลอย ๆ

> ประเด็นที่ควรพิจารณาเพิ่มเติมคือต้นทุนที่มองไม่เห็นในงบการเงิน ได้แก่ เวลาของเจ้าของกิจการที่ใช้ตรวจทานรายงาน ...
> ต้นทุนอีกกลุ่มหนึ่งที่งานส่วนใหญ่ไม่ได้นับคือ ...
> ในกรณีของประเทศไทย ...
> หากมองจากฝั่งผู้ประกอบการ ...

### ช. ย่อหน้าแย้งหรือจำกัดขอบเขต (แทน "อย่างไรก็ตาม" ต้นย่อหน้าทุกครั้ง)

> อย่างไรก็ดี ข้อสรุปข้างต้นมิได้หมายความว่ากิจการขนาดเล็กทุกแห่งจะได้ประโยชน์เท่ากัน ...
> กระนั้น ความได้เปรียบดังกล่าวผูกอยู่กับ ...
> ข้อจำกัดของหลักฐานชุดนี้คือ ...
> ผลข้างต้นใช้ได้เฉพาะ ...

"อย่างไรก็ดี" และ "อย่างไรก็ตาม" ใช้ได้ แต่ไม่ควรเปิดย่อหน้าเกิน 2 ครั้งต่อบทความ

### ซ. ปิดหัวข้อใหญ่

ปิดด้วยสิ่งที่หัวข้อนี้ให้แก่หัวข้อถัดไป ไม่ใช่ประโยคขยายความสำคัญ

> สรุปได้ว่า หลักฐานในส่วนนี้ชี้ว่าการมีระบบอิเล็กทรอนิกส์เพียงอย่างเดียวไม่ลดต้นทุน ต้นทุนจะลดเมื่อข้อมูลไหลเข้าระบบบัญชีโดยไม่ต้องคีย์ซ้ำ ซึ่งเป็นเงื่อนไขที่หัวข้อถัดไปจะวิเคราะห์

ห้ามปิดด้วย "...ซึ่งสะท้อนให้เห็นถึงความสำคัญของ..." "...จึงเป็นสิ่งที่ไม่อาจมองข้ามได้" "...ถือเป็นกุญแจสำคัญ..."

### ฌ. อธิบายกฎหมายหรือมาตรการ

ยกเงื่อนไขตามตัวบทให้ครบ แล้วค่อยบอกว่ามาตรการนั้นมุ่งอะไร โดยไม่ตีความผลเกินตัวบท

> มาตรา 5 แห่งพระราชกฤษฎีกาฉบับนี้ให้กิจการที่เข้าเงื่อนไขได้รับยกเว้นภาษีเงินได้สำหรับเงินได้จำนวนเท่ากับรายจ่ายที่จ่ายจริงในช่วงวันที่ ... ถึง ... เฉพาะรายจ่ายที่ ... มาตรการนี้จึงมุ่งลดต้นทุนเริ่มต้นของการเข้าสู่ระบบ ส่วนผลต่อต้นทุนการปฏิบัติตามกฎหมายในระยะยาวยังต้องประเมิน

ข้อความที่คัดจากตัวบทให้ครอบด้วย `[ตัวบท]...[/ตัวบท]` ในร่าง เพื่อให้ขั้นปรับสำนวนและสคริปต์ตรวจไม่แตะ ลบป้ายออกก่อนสร้าง .docx (`build_docx.py` ลบให้อัตโนมัติ)

### ญ. เสนอกรอบแนวคิดของผู้เขียน

> จากหลักฐานข้างต้น ผู้เขียนเสนอกรอบแนวคิดที่มีองค์ประกอบสามส่วน ได้แก่ ... กรอบนี้ยังไม่ได้ทดสอบเชิงประจักษ์ ข้อเสนอแต่ละข้อจึงเขียนเป็นสมมติฐานที่งานวิจัยต่อไปทดสอบได้ ดังนี้

## คลังคำเชื่อมและกริยาวิชาการไทย

ใช้ตามความหมายจริง ไม่ใช่ใส่เพื่อให้ดูเป็นวิชาการ

| หน้าที่ | คำที่ใช้จริง | หมายเหตุ |
|---|---|---|
| ขยายความ/นิยาม | กล่าวคือ, หมายความว่า, ได้แก่, เช่น, อาทิ | "กล่าวคือ" ตามด้วยคำอธิบายที่ละเอียดกว่า ไม่ใช่ซ้ำความเดิม |
| เหตุ→ผล | จึง, ทำให้, ส่งผลให้, เพราะ, เนื่องจาก, ด้วยเหตุนี้ | "จึง" กลางประโยคเป็นธรรมชาติกว่า "ดังนั้น" ต้นประโยค |
| แย้ง/จำกัด | แต่, กลับ, กระนั้น, อย่างไรก็ดี, ทว่า, แม้...แต่ | "แม้ ... ก็ตาม แต่" ซ้อนกันคือร่องรอยแปล |
| เสริม | อีกทั้ง, ทั้งยัง, รวมทั้ง, นอกจากนี้ (ไม่เกิน 2-3 ครั้ง/บทความ), อนึ่ง | "อนึ่ง" ใช้เปิดข้อสังเกตแยกออกมา |
| เงื่อนไข | หาก, เมื่อ, ในกรณีที่, ต่อเมื่อ, เว้นแต่ | "ถ้า" ใช้ได้แต่ "หาก" เป็นทางการกว่า |
| ยืนยันเชิงตรรกะ | ย่อม, ย่อมต้อง, จำต้อง, มิอาจ | "ย่อม" บอกผลที่ตามมาโดยธรรมชาติ ใช้ 2-3 ครั้งพอ |
| ปฏิเสธทางการ | มิได้, มิใช่, ไม่ได้, ไม่ใช่ | "มิใช่...หากแต่..." ใช้ได้ไม่เกิน 1-2 ครั้ง |
| อ้างถึงก่อนหน้า | ดังกล่าว, ข้างต้น, ดังที่กล่าวแล้ว, ในส่วนก่อนหน้า | "ดังกล่าว" ซ้ำทุกประโยคก็สะดุด |
| สรุป | สรุปได้ว่า, โดยสรุป (เฉพาะส่วนสรุป), ทั้งหมดนี้ชี้ว่า | "กล่าวโดยสรุป" กลางเรื่องคือร่องรอย AI |
| บอกระดับความมั่นใจ | พบว่า > แสดงว่า > ชี้ว่า > บ่งชี้ว่า > น่าจะ > อาจ > ผู้เขียนสันนิษฐานว่า | เลือกระดับเดียวต่อประโยค ห้ามซ้อน "อาจจะมีแนวโน้มที่จะ" |

## คำที่แปลตรงจากอังกฤษจนสะดุด (เพิ่มจาก thai-humanizer.md)

| สำนวนแปล | ต้นทางภาษาอังกฤษ | เขียนเป็นไทย |
|---|---|---|
| "ทำการศึกษา / ทำการวิเคราะห์" | conduct a study | "ศึกษา / วิเคราะห์" |
| "มีความสำคัญ / มีความจำเป็น / มีความซับซ้อน" ซ้ำ ๆ | is important / necessary / complex | "สำคัญ / จำเป็น / ซับซ้อน" หรือบอกว่าสำคัญต่ออะไร |
| "ในแง่ของ" | in terms of | "ด้าน" หรือเรียงประโยคใหม่ |
| "ในส่วนของ X" ต้นประโยคทุกครั้ง | as for X | ให้ X เป็นประธานเลย |
| "เป็นที่น่าสังเกตว่า" | it is worth noting that | "ข้อที่น่าสังเกตคือ" หรือตัดแล้วบอกข้อสังเกตเลย |
| "มีแนวโน้มที่จะ" ทุกประโยค | tend to | "มัก" |
| "X ของ Y ของ Z" สามชั้น | possessive chain | ตัดเป็นสองวลี หรือใช้ "ใน/สำหรับ" |
| "การ...การ...การ..." ซ้อน | nominalization chain | เหลือ "การ" ตัวเดียว ที่เหลือใช้กริยา |
| "ซึ่งกันและกัน" | each other | "กัน" |
| "เพื่อที่จะ" | in order to | "เพื่อ" |
| "สามารถ...ได้" ทุกประโยค | can / be able to | ใช้เมื่อหมายถึงความสามารถจริง ไม่ใช่ทุก "can" |
| "ได้รับการ..." เพื่อเลี่ยง "ถูก" ทุกครั้ง | passive | เปลี่ยนเป็นประโยคกรรตุ: ใครทำ |
| "หนึ่งใน...ที่สำคัญที่สุด" | one of the most important | "...ที่สำคัญ" หรือบอกว่าสำคัญอย่างไร |
| "ไม่ว่าจะเป็น A, B หรือ C" เปิดรายการทุกครั้ง | whether A, B, or C | "ได้แก่" หรือ "เช่น" |
| "ส่งผลกระทบต่อ" ทุกครั้ง | impact on | "กระทบ / ทำให้...ลดลง/เพิ่มขึ้น" บอกทิศทาง |
| "ให้ความสำคัญกับ" | place emphasis on | "เน้น" |
| "ถือได้ว่า / ถือเป็น" ซ้ำ | is considered | ตัด หรือบอกว่าใครถือ |
| "มีส่วนร่วมในการ" | participate in | "ร่วม..." |
| "ด้วยเหตุนี้ / ด้วยเหตุผลดังกล่าว" ต้นย่อหน้า | for this reason | "จึง" ในประโยคถัดไป |
| ลำดับ "ตัวเลข + คำนาม" แบบอังกฤษ "200 ผู้ประกอบการ" | 200 entrepreneurs | "ผู้ประกอบการ 200 ราย" (นาม + เลข + ลักษณนาม) |
| "%" ในเนื้อหา | 12% | "ร้อยละ 12" (ในตารางใช้ % ได้) |

## ขั้นตอนใช้ไฟล์นี้ตอนร่าง

1. ก่อนเขียนแต่ละหัวข้อ ดู outline แล้วเลือกแม่แบบย่อหน้า (ก-ญ) ให้แต่ละย่อหน้า
2. เขียนจากโน้ตไทยใน refs.json ไม่เปิดบทคัดย่ออังกฤษขณะเขียน
3. เขียนเสร็จหนึ่งหัวข้อ อ่านออกเสียงในใจทีละประโยค ถามว่า "อาจารย์ไทยพูดแบบนี้ไหม"
4. รัน `scripts/thai_style_check.py` ดูตัวเลขร่องรอยก่อนไปหัวข้อถัดไป
5. เมื่อเขียนครบ ใช้ `thai-humanizer.md` เก็บตก
